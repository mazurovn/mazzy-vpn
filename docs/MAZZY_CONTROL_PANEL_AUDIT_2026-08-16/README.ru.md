# Видимые артефакты аудита Mazzy Control Panel

## logs

Сохранённые test/typecheck логи Control Panel, VPN plugin и MAZZY_VPN. Логи относятся к конкретным запускам и не являются универсальными SLA.

## agents

Только безопасные итоговые handoff-отчёты трёх child runs. Полные transcripts, prompts, hidden reasoning и capability data намеренно не публикуются.

## metrics

Synthetic sequential localhost benchmark и агрегированные VPN-consilium usage/cost metrics.

Все файлы доступны в обычной папке `docs`, а не только в скрытой `.mazzy`.
