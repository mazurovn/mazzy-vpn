## Правила интерпретации

- `ORIGINAL_FULL_REPORT.ru.md` и канонический исходный отчёт должны иметь одинаковый SHA-256.
- `SHORTENED_CONSILIUM_REPORT.ru.md` хранится только для аудита нарушения директивы.
- Версия 2 является рекомендуемым документом для чтения: она включает полный оригинал, консилиум и issue log.
- Transcript/hidden reasoning, prompts, capability URLs, access tokens и credentials в комплект не включались.
- Test logs отражают конкретный worktree и время запуска; benchmark является synthetic sequential localhost observation, а не SLA.
