# ADR-0001: Язык реализации — нативный Go

- Статус: **ПРИНЯТО** (зафиксировано заказчиком)
- Дата: 2026-08
- Контекст: полное переписывание MAZZY_VPN с bash на компилируемый язык.

## Решение

Весь стек (CLI, TUI, Desktop, Android, движок `mazzy-core`) реализуется на
**нативном Go**.

## Рассмотренные альтернативы

Заказчик просил оценить Nim и Zig, при жёстком ограничении «FFI-мост не
рассматриваю». Это ограничение — решающее.

### Измерения объёма AmneziaWG (факты, не оценки)

Из `amneziawg-go/v3@v3.0.1` (Linux, без тестов):

| Компонент | LOC |
|---|---:|
| `device/` (протокол WG + handshake + obfuscation) | 6 242 |
| `conn/` (UDP-биндинги) | 1 311 |
| `tun/` (Linux TUN, netstack) | 1 844 |
| `ipc/ replay/ ratelimiter/ tai64n/ rwcancel/` | ~700 |
| **Ядро (только Linux)** | **~10 000** |

Дополнительно вся Noise-криптография (Curve25519, ChaCha20-Poly1305, BLAKE2s,
Poly1305) в Go берётся из `golang.org/x/crypto`. Amnezia-специфичный слой
(`obf_*.go`) — всего **305 LOC**, но он бесполезен без ~10 000 строк WireGuard
под ним.

### Сравнение

| Критерий | Go | Zig | Nim |
|---|---|---|---|
| AmneziaWG-движок | готов (vendored, тот же язык — НЕ FFI) | переписать ~10k LOC WG | то же + нет крипты в stdlib |
| Noise-примитивы | x/crypto | std.crypto | libsodium(FFI) или порт |
| TUN/UDP/routes | stdlib | ручной syscall | ручной |
| TUI-экосистема | bubbletea/lipgloss | слабая | слабая |
| Desktop без Tauri | Wails/gio/Fyne | практически нет | практически нет |
| Срок до продукта | недели | месяцы (форк WG) | месяцы |

## Обоснование

1. **«Без FFI» исключает Nim и Zig для движка.** Go + vendored `amneziawg-go` —
   это НЕ FFI: один язык, одна компиляция, один статический бинарник. Zig/Nim
   без FFI = переписать весь WireGuard (~10k LOC криптосети) на новом языке —
   это форк проекта WireGuard, а не переписывание MAZZY_VPN.
2. **Максимум переиспользования:** движок уже есть на Go и уже используется в
   Android (`android/amneziawg-tunnel/native/libwg-go`).
3. **Один язык на три продукта** + общий `internal/core`.
4. **Автономность:** статическая линковка даёт один самодостаточный бинарник.

## Последствия

- Zig оставляем как долгосрочную R&D-цель (чистый AmneziaWG на Zig), вне
  текущего scope.
- Переписывание bash-логики (jq/awk/timeout) на Go stdlib — упрощение, не риск.
