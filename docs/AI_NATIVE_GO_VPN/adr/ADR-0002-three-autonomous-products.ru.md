# ADR-0002: Три самодостаточных продукта на общем ядре

- Статус: **ПРИНЯТО** (зафиксировано заказчиком)
- Дата: 2026-08

## Решение

MAZZY_VPN разделяется на **три отдельных продукта**, каждый самодостаточен:

1. **mazzy-vpn-cli** — CLI + TUI, один автономный бинарник.
2. **mazzy-vpn-desktop** — десктоп-приложение (Go GUI), автономно **от CLI**.
3. **mazzy-vpn-android** — Android-приложение, автономно от CLI.

Все три линкуют **общее ядро** `internal/core` (`mazzy-core`) в свой бинарник.

## Ключевое требование заказчика

- Desktop **может и должен работать независимо от CLI**. Он НЕ вызывает
  бинарник CLI; он встраивает `mazzy-core` напрямую.
- Android так же: встраивает `mazzy-core` (gomobile/JNI), не зависит от CLI.
- Ни один продукт не зависит от внешних библиотек в рантайме.

## Целевая структура репозитория

```
mazzy-vpn-cli/          продукт 1
  cmd/mazzy-vpn/         точка входа CLI
  internal/tui/          TUI-меню
mazzy-vpn-desktop/       продукт 2 (Go GUI: Wails или gio/Fyne — см. ADR-0004)
mazzy-vpn-android/       продукт 3 (gomobile + Kotlin UI)
core/                    ОБЩЕЕ ЯДРО mazzy-core (Go module)
  wireguard/             vendored amneziawg-go как библиотека
  openvpn/               vendored статик или нативный (см. ADR-0003)
  tun/ routes/ dns/ nft/ автономная замена *-quick
  connect/ health/ doctor/ profile/ state/ probe/
  api/                   локальный machine-first API (JSON)
```

`core/` — единственный источник правды движка. Дублирование логики между
продуктами запрещено.

## Почему не «CLI как бэкенд для Desktop»

Текущий Desktop (Tauri) частично вызывает CLI. Заказчик недоволен его работой и
требует независимости. Модель «Desktop → CLI-бинарник» создаёт:

- скрытую зависимость (Desktop не работает без установленного CLI),
- дублирование парсинга/состояния,
- хрупкий IPC.

Общее ядро-библиотека убирает эти проблемы: каждый продукт полноценен сам.

## Последствия

- Переходный период: пока Go-ядро не готово, продукты сосуществуют со старыми
  реализациями.
- Требуется дисциплина: любая логика движка — только в `core/`.
