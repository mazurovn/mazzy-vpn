# Правила проекта AI-NATIVE-GO-VPN

Статус: **NORMATIVE** (обязательны к соблюдению). Дата: 2026-08.

## 1. Язык и стек

- Весь новый код — **нативный Go**. Никаких bash-скриптов в роли рантайм-логики
  (кроме тонких обёрток установки/сервисов, где это неизбежно).
- Внешние вызовы `jq`, `awk`, `sed`, `timeout`, `socat`, `python3` заменяются
  на стандартную библиотеку Go. Их наличие в системе **не должно требоваться**.

## 2. Автономность (жёсткое требование заказчика)

### CLI
- CLI работает **полностью автономно от всех библиотек и самодостаточен**.
- Один статически слинкованный бинарник. `mazzy-core` (WireGuard/AmneziaWG)
  встроен как Go-библиотека, **не** как внешний `awg`/`awg-quick`/`wg`.
- Установка **не клонирует и не собирает** внешние репозитории
  (никаких `git clone amneziawg-*`, никаких обязательных `apt install openvpn`).

### Desktop
- Desktop **самодостаточен и автономен от библиотек И от CLI**.
- Desktop может и **должен работать независимо от CLI**: встраивает тот же
  `mazzy-core` напрямую, не вызывает бинарник CLI.

### Android
- Android так же самодостаточен: встраивает `mazzy-core` (gomobile/JNI),
  не зависит от CLI и от внешних установок.

Общий принцип: `internal/core` (`mazzy-core`) — **единственная** общая
кодовая база движка; каждый из трёх продуктов линкует её в свой бинарник.

## 3. Публикация и секретность (жёсткое требование заказчика)

- **В GitHub публикуются только готовые исходники и описание** (Go-исходники
  трёх продуктов и design-docs под `docs/`).
- **НЕ публикуются:** оркестрация, форк Control Panel, транскрипты, промпты,
  скрытые рассуждения, бэклог-БД, состояние сервера, evidence-логи.
- Форк Control Panel живёт в `tools/mazzy-control-panel/` и **целиком исключён**
  из git (`.gitignore`). См. `tools/mazzy-control-panel/FORK_NOTICE.md`.
- Локальный control-plane workspace — `.mazzy-vpn-control/` — git-ignored.
- `.pi-ops/` (состояние локального сервера/бэклога) — git-ignored.

## 4. Локальный Control Panel (изоляция от общей базы)

- Используется **проектный форк** `@mazzy-vpn/control-local`, а не общий
  `@mazzy/control`, чтобы «не шуметь в базе» лаборатории.
- Форк держит **свой сервер и свой бэклог** внутри проекта.
- Это разрешённое исключение: инструмент локальный и непубличный.

## 5. Аудит и качество

- Каждое крупное архитектурное решение проходит **цикл проверок + консилиум**
  топовых агентов (fresh-context review), как в предыдущем аудите
  (`docs/MAZZY_CONTROL_PANEL_AUDIT_2026-08-16/`).
- Артефакты аудита: только безопасные итоговые отчёты в `docs/.../audit/`.
- Паритет логики с текущим bash-CLI (guard/lease/recovery/doctor) обязателен:
  зрелую логику самолечения нельзя терять при переписывании.

## 6. Совместимость на переходный период

- Старый bash `mazzy-vpn` остаётся рабочим, пока Go-CLI не достигнет паритета.
- Ничего в проде не ломаем: миграция инкрементальная, по фазам бэклога.
