# Раунд 4 аудита — self-audit routes/dns/guard (Фаза 1)

- Дата: 2026-08
- Область: `core/routes`, `core/dns`, `core/guard`, `core/netexec`.
- Метод: adversarial сравнение с wg-quick `linux.bash` (паритет).

## Найденные дефекты

### G1 — P0 — Рассинхрон fwmark сокета и таблицы маршрутизации (обрыв связи)
**Суть:** wg-quick использует **одно и то же** число как fwmark сокета
WireGuard и как номер таблицы. Правило `ip rule add not fwmark <t> table <t>`
означает: пакеты БЕЗ метки `<t>` идут в тоннель. Собственные зашифрованные
UDP-пакеты движка помечены `<t>` и потому обходят тоннель, уходя в реальный
интерфейс.

**Мой баг:** `routes` использует таблицу 51820, но UAPI ставит `fwmark` только
если `cfg.FwMark != 0`. Значит сокет движка **не помечен** → зашифрованный
трафик матчит `not fwmark 51820` → зацикливается в тоннель → **нет связи**.

**Исправление:** ввести единый эффективный mark, применяемый И к движку (UAPI
`fwmark=`), И к таблице маршрутов. `routes` и `engine` берут его из одного
источника.

### G2 — P1 — Не установлен `net.ipv4.conf.all.src_valid_mark=1`
wg-quick для v4 ставит этот sysctl, иначе ответные помеченные пакеты могут
отбрасываться rp_filter. Пропущено.

**Исправление:** ставить sysctl при добавлении v4 default route.

### G3 — P2 — Нет CONNMARK save/restore
wg-quick добавляет nft/iptables правила CONNMARK (`save-mark`/`restore-mark`)
для корректной пометки ответных соединений. Пропущено.

**Исправление:** добавить в `guard`/`routes` nft-правила CONNMARK (задача
C1-4a2), пометить как техдолг паритета до privileged smoke.

### G4 — P2 — resolvconf-бэкенд DNS не реализован (нужен stdin)
`dns` поддерживает только `resolvectl`. Для систем без systemd-resolved
resolvconf-путь возвращает явную ошибку (не молчит) — приемлемо на этап 1,
задача C1-4b2.

## Что уже правильно (подтверждено тестами)

- Политика suppress_prefixlength и структура правил — паритет.
- nft-рулсеты IPv6-guard и fail-closed — точный паритет с bash (тесты читают
  реальный ruleset-файл).
- Никакого shell: `netexec` запрещает control-символы, только argv.
- Идемпотентность guard: таблица удаляется перед установкой.
