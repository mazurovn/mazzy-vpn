## Найденные и исправленные дефекты

### Q1 — dead code — ИСПРАВЛЕНО
`staticcheck` нашёл 2 реально мёртвых элемента в НАШЕМ коде:
- `probe/probe.go`: поле `lastReason` — не читалось и не писалось. Удалено.
- `routes/routes.go`: метод `ipArgs` — заменён `famFlag`, стал недостижим.
  Удалён.

Остальные тысячи «unused» из наивного grep — это vendored
`golang.org/x/sys` syscall-обёртки (не наш код), staticcheck их корректно
игнорирует.

## Проверки, прошедшие без замечаний

### Пустые пакеты / заглушки — НЕТ
LOC по пакетам: profile 381, api 219, routes 151, state 139, connect 124,
verify 113, bootrecovery 114, probe 106, guard 101, health 95, doctor 94,
livetest 78, wireguard 77, lock 74, netexec 58. Пустых/заглушечных нет;
самый маленький (`netexectest` 15) — намеренный тестовый fake.

### Хардкод — НЕТ в логике
Grep по URL/IP/путям/портам: попадания только в (а) комментарии-примеры
(`e.g. /var/lib/mazzy-vpn`), (б) demo-конфиг `cmd/engine-selftest` (тестовые
данные `10.8.0.2`, `1.1.1.1`). В рабочей логике абсолютных путей/URL/IP нет.
Магические числа вынесены в именованные константы: `DefaultMark=51820`,
`DefaultMTU=1420` (из библиотеки).

### Спагетти — НЕТ
Самые длинные функции: `connect.Up` (72), `doctor.Run` (65), `verify.Evaluate`
(59), `api.Dispatch` (54). Все линейны по структуре (последовательные шаги с
early-return), не превышают порог цикломатической сложности (>15 ветвлений —
ноль функций). Дублирования логики между пакетами нет.

### Игнорирование ошибок — ТОЛЬКО намеренно
`_ =` встречается 10 раз, все — корректные best-effort пути: cleanup temp
(`state`, `guard/tempfile`), best-effort rollback в error-путях (`livetest`),
идемпотентный `nft delete table` (`guard`). Ни одной проглоченной значимой
ошибки на success-пути.

### Логическая консистентность — ПОДТВЕРЖДЕНА
`connect.Down` и `connect.unwind` откатывают ОДНИ И ТЕ ЖЕ слои в ОДНОМ порядке
(dns→routes→engine→guard) — нет риска расхождения при двойном сопровождении.
Все error-пути `api` возвращают либо контролируемый `HandlerError`, либо
generic `api.internal` (нет утечки).

## Вывод

Код используется, не пустой, без хардкода в логике, без спагетти, без мёртвых
функций (после фикса Q1) и без проглоченных ошибок. Инструментальные gate
(vet/staticcheck/gofmt/-race) — зелёные и добавлены в чек-лист качества.
