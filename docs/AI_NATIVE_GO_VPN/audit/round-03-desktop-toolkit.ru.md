# Раунд 3 аудита — GUI-тулкит Desktop (самодостаточность)

- Дата: 2026-08
- Область: ADR-0004, требование заказчика «ничего не доустанавливать, не
  зависеть от библиотек, клиент самодостаточен».
- Метод: проверка реальных runtime-зависимостей тулкитов на целевой системе.

## Ключевой критерий

Требование заказчика разложено на две категории зависимостей:

1. **Базовая графика ОС** (X11/Wayland/OpenGL/EGL/xkbcommon) — есть на любом
   Linux-десктопе. Использование НЕ нарушает самодостаточность.
2. **Тяжёлый рантайм-фреймворк** (webkit2gtk/GTK/Electron/.NET) — пользователь
   вынужден доустанавливать → **нарушает требование**.

## Проверка (факты на целевой системе)

| Зависимость | Наличие |
|---|---|
| libGL/libEGL/libX11/libwayland/libxkbcommon/libvulkan | все есть по умолчанию |
| Сессия | Wayland |
| webkit2gtk | присутствует, но тяжёлая внешняя зависимость (это и есть Tauri-боль) |

## Вывод

| Тулкит | Тянет пользователю | Вердикт |
|---|---|---|
| **gio** | только базовая графика ОС | ✅ выбран |
| Fyne | базовая графика + свой look | приемлем, но тяжелее |
| Wails | webkit2gtk/GTK-рантайм | ❌ нарушает требование |
| Tauri | webkit2gtk | ❌ текущая боль |

**Решение:** Desktop на **gio** — единственный вариант без внешнего
webview/GTK-рантайма, чистый Go, один статический бинарник, линкует общий
`core/`, работает без CLI.

## Осознанные компромиссы

- UX пишется с нуля (нельзя переиспользовать web-фронт) — цена
  самодостаточности.
- Трей/автозапуск — отдельные задачи (gio трей не даёт): P3-3a.
- cgo+dev-заголовки нужны на **сборочной** машине (есть), не у пользователя.

## Статус

ADR-0004 → ПРИНЯТО. F0-7 закрыт. Проверить фактический рендер на Wayland+X11
целевых DE — задача P3-3b.
