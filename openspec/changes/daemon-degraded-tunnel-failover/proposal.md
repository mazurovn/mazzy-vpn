# Proposal

## Why

Инцидент 2026-09-21 (asus750, профиль NetherlandsAmsterdamS4-1, AmneziaWG): демон `mazzy-vpn daemon --best` 18 минут держал полумёртвый туннель. Лог `/run/mazzy-vpn/daemon.log`:

```
18:16:07 ✔ protected. egress=78.31.250.57
18:16:37 egress probe failed but handshake fresh (0s ago): ... (1/6)
18:17:07 egress probe failed but handshake fresh (30s ago): ... (1/6)
... (ещё 25 строк «(1/6)», один раз «(2/6)») ...
18:34:47 disconnect requested   ← пользователь убил демон руками
```

Причины по коду `mazzy-vpn-cli/cmd/mazzy-vpn/daemon.go`:

1. Счётчик `softFails` **сбрасывается в 0 любой одной удачной пробой**. При ~50 % потерь на data-path проба чередуется «упала / прошла», счётчик никогда не доходит до `softFailLimit = 6`, и failover не наступает.
2. «Свежий handshake» трактуется как признак живого туннеля. Но handshake обновлялся **каждые ~30 с** (норма 2–3 мин): WireGuard пересогласовывается именно потому, что его data-пакеты остаются без ответа. Т.е. это признак *мёртвого* data-path, а код считает наоборот.

Пользователь воспринимает это как «VPN постоянно отваливается»: ICMP через туннель — 100 % потерь, HTTPS-пробы таймаутят по 20 с, а демон рапортует «protected» и не переключает зону. За сегодня пользователь 5 раз перезапускал демон вручную (NL → NL → DK → BE → NL).

## What Changes

- Health-check демона получает **скользящее окно исходов проб** (`probeWindow = 12`): ≥ `probeLossLimit = 5` неудач в окне считается потерей egress независимо от того, идут ли они подряд.
- `softFails` при удачной пробе **уменьшается на 1, а не обнуляется**.
- Добавлен детектор **handshake churn**: ≥ `hsChurnLimit = 4` подряд «молодых» (< 90 с) пересогласований handshake → data-path мёртв → реконнект/failover.
- Оба сигнала проверяются и на удачном тике (`s.Protected()`): удачная проба на деградировавшем туннеле ведёт в тот же путь реконнекта.
- Все накопители сбрасываются при teardown туннеля.

## Capabilities

### New Capabilities
- `daemon-liveness`: правила, по которым фоновый демон решает, что туннель деградировал, и инициирует реконнект/failover.

### Modified Capabilities
(нет — существующих спеков в проекте пока нет)

## Impact

- Код: только `mazzy-vpn-cli/cmd/mazzy-vpn/daemon.go` (цикл health-check).
- Поведение: демон переключит зону через ~1–2 мин деградации вместо «никогда». Ложных срабатываний на здоровом туннеле не ожидается: здоровый туннель даёт < 5 неудач из 12 и handshake раз в 2–3 мин.
- Совместимость: без изменений CLI/API/форматов; новые поля только в тексте лога.
